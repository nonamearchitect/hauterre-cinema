🔐 영구 보관 연결이 필요해요 (한 번만)

지금은 업로드한 영상이 서버가 잠들면 사라지는 임시 저장 상태입니다. 아래를 한 번만 해 두면 영상과 상영목록이 Hugging Face에 영구 보관됩니다(무료).
1) Hugging Face 토큰 만들기 → 이름 아무거나, 종류 Write → 만든 토큰 복사
2) Render 서비스 → Environment → HF_TOKEN 값에 붙여넣고 저장 (자동 재시작)
