# HAUTERRE BRAND CINEMA: 실시간 메타버스 극장

링크를 받은 사람은 누구나 브라우저로 바로 입장합니다(앱 설치 없음, PC·모바일 모두 가능).
입장한 관객끼리 실시간으로 서로를 보고, 빈 좌석에 앉아 브랜드 영상을 **모두 같은 장면으로** 함께 봅니다.

| 주소 | 용도 |
|---|---|
| `/` | 극장 (관객용) |
| `/admin` | 상영 관리: 영상 업로드, 순서·제목 변경, 인터미션 시간 설정 |

---

## 1. 내 PC에서 실행하기

**처음 한 번만**
1. https://nodejs.org 에 접속해 왼쪽 **LTS** 버튼을 눌러 설치합니다(설치 중 옵션은 기본값 그대로 두고 "다음").
2. `brand-cinema.zip` 압축을 바탕화면 등 원하는 곳에 풉니다.

**실행할 때마다**
1. 폴더 안의 `start-windows.bat` 를 더블클릭합니다(Mac은 `start-mac.command`, 처음에는 우클릭 → 열기).
   - Windows 보안 경고가 뜨면 "추가 정보 → 실행"을 누릅니다.
   - 방화벽 창이 뜨면 "허용"을 누릅니다.
2. 검은 창이 뜨고 아래처럼 표시됩니다. **이 창을 닫으면 극장이 꺼집니다.**
   ```
   ▶ 관람 주소      http://localhost:8080
   ▶ 관리자(영상)   http://localhost:8080/admin
   ▶ 같은 사내망/와이파이 동료  http://192.168.x.x:8080
   ▶ 관리자 비밀번호 3fa9c01b2e
   ```
3. 브라우저가 자동으로 극장을 엽니다.
4. 영상을 올리려면 **http://localhost:8080/admin** 에 들어가 비밀번호를 입력합니다.

> 같은 사무실 네트워크에 있는 동료는 `http://192.168.x.x:8080` 주소로 바로 들어올 수 있습니다(사내 방화벽 정책에 따라 막힐 수 있음).
> `index.html` 을 더블클릭해서 여는 방식은 작동하지 않습니다. 반드시 위 방법으로 실행하세요.

## 2. 영상 올리기 (관리자 화면)

1. `/admin` 에 들어가 비밀번호를 입력합니다.
2. **① 영상 올리기**: MP4 파일을 끌어다 놓으면 업로드되고, 상영목록에 자동으로 추가됩니다.
3. **② 상영목록**: 제목을 고치고 ↑↓로 순서를 바꿉니다. 데모 영상은 "목록에서 빼기"로 뺍니다.
4. 아래 **적용하기**를 누르면 **지금 접속해 있는 모든 관객 화면이 바로 바뀝니다.** 인터미션 카운트다운 후 1번 영상부터 상영됩니다.

- 영상은 **H.264 MP4**를 권장합니다. 아이폰 HEVC나 .mov 원본은 브라우저에서 재생되지 않을 수 있습니다.
  재생이 안 되는 파일은 관리자 화면에 ⚠ 표시가 뜹니다.
- 유튜브 링크는 3D 스크린에 입힐 수 없습니다. 원본 MP4를 올려 주세요.
- 비밀번호는 `server/data/admin-password.txt` 파일을 고쳐서 바꿀 수 있습니다. 바꾼 뒤에는 서버를 다시 실행하세요.

**영상 변환이 필요할 때 (ffmpeg)**
```
ffmpeg -i 원본.mov -c:v libx264 -crf 22 -maxrate 8M -bufsize 16M -vf scale=1920:-2 -c:a aac -b:a 160k -movflags +faststart 결과.mp4
```
(무료 프로그램 HandBrake의 "Fast 1080p30" 프리셋으로 변환해도 됩니다.)

## 3. 외부 공개: 전부 무료 (Render + Hugging Face)

| 역할 | 무료 서비스 | 비고 |
|---|---|---|
| 극장 서버 (실시간 접속 + 페이지) | **Render** 무료 웹 서비스 | 15분 동안 접속이 없으면 잠들고, 다음 접속 때 약 1분 뒤 깨어남 |
| 영상 보관·재생 | **Hugging Face Dataset** | 파일당 최대 50GB, 전송량 과금 없음 |
| 코드 보관 | **GitHub** 저장소 | Render가 여기서 코드를 가져감 |

1. **GitHub:** 저장소 `hauterre-cinema`를 Public으로 만들고, 이 폴더 안의 파일을 전부 업로드합니다(Add file → Upload files).
2. **Render:** https://render.com 에 GitHub 계정으로 가입합니다.
   **New → Blueprint**에서 위 저장소를 고르면 `render.yaml` 설정(무료 플랜, 싱가포르 리전)이 자동으로 적용됩니다.
3. 배포가 끝나면 `https://hauterre-cinema-xxxx.onrender.com` 이 생깁니다. 이게 **공유 링크**입니다.
   관리자 비밀번호는 Render의 서비스 → **Environment** 탭에 있는 `ADMIN_PASSWORD`에서 확인합니다.
4. **영상:** Hugging Face Dataset에 MP4를 올리고, 그 파일의 다운로드 주소를 `/admin`의 **"주소로 추가"**에 넣습니다.

### 무료 운영 시 알아둘 점
- **15분 동안 접속이 없으면 서버가 잠듭니다.** 다음 사람은 약 1분간 로딩 화면을 봅니다.
  행사 기간에 계속 깨워 두려면, 무료 서비스 cron-job.org 에서 `https://주소/health`를 10분마다 호출하도록 설정하세요. 무료 사용 시간(월 750시간) 안에서 한 달 내내 켜 둘 수 있습니다.
- **서버가 잠들었다 깨면 관리자 화면에서 바꾼 상영목록이 초기화됩니다.**
  계속 유지하려면 GitHub의 `public/config.js` `playlist`에 영상 주소를 적어 두세요(GitHub 웹에서 연필 아이콘으로 수정하면 Render가 자동으로 다시 배포합니다).
- 관리자 화면의 **직접 업로드는 재시작하면 사라지니**, 영상은 Hugging Face Dataset에 올리세요.

### 영상 용량 권장
4~5GB 원본은 관객 데이터 부담이 큽니다. 무료 프로그램 HandBrake의 **"Fast 1080p30"** 으로 변환해 1~2GB로 줄이는 것을 권장합니다.

## 4. 관람객 경험과 성과 측정 (v2)
- **4 MOMENTS**: 오티에르 핵심가치 4가지를 미션으로 만들었습니다(착석 · 30초 감상 · 매점 · 응원/축포). 4개를 모두 달성하면 이름이 들어간 **관람 인증서**(인스타그램 세로 비율)가 발급됩니다.
- **📸 사진**: 오티에르 로고 프레임이 들어간 기념사진을 찍어 저장합니다.
- **👏 커튼콜**: 관객 전체의 박수·반응·축포가 게이지를 채우면 모두의 화면에 커튼콜 쇼(축포 + 스파클러 + 조명)가 열립니다.
- **엔딩 카드**: 상영을 일정 시간 이상 본 관객에게만, 상영이 끝나면 한 번 브랜드 링크(CTA)와 공유 버튼을 보여 줍니다. 링크는 `config.js`의 `cta`에서 바꿉니다.
- **관람 현황**: 관리자 화면 맨 위에서 방문자 수, 최대 동시접속, 착석률, 완주, 인증서·사진·공유, CTA 클릭과 전환율을 확인할 수 있습니다(`server/data/stats.json`에 저장).

## 4-1. 동시 접속과 안전
- 한 홀에는 80명까지 들어가고, 넘으면 같은 구성의 홀이 자동으로 추가됩니다(`ROOM_MAX`로 조정).
- 상영은 **서버 시각 기준 시간표**로 돌아가서, 누가 언제 들어와도 같은 장면을 봅니다.
- 채팅은 정해진 문장만 고를 수 있습니다(욕설·개인정보 걱정 없음). 중복 착석 방지와 요청 속도 제한도 서버에서 처리합니다.
- 관리자 기능은 비밀번호로 보호되고, 영상 파일(MP4/WEBM)만 업로드할 수 있습니다.
- 상태 확인: `/health` (현재 접속자 수)

## 5. 문구·로고 바꾸기
`public/config.js` 에서 바꿉니다. 로고(`brand/hauterre-logo.png`), 전광판 문구, 말풍선 문장, 관객 색상을 설정할 수 있습니다.

## 6. 폴더 구조
```
public/              ← 웹페이지 (공개)
  config.js          ← 문구·로고·말풍선 설정
  admin.html         ← 상영 관리 화면
  brand/             ← 오티에르 로고
  media/             ← 업로드된 영상 (기본 위치)
  js/                ← 3D 극장, 캐릭터, 실시간 통신
server/relay.mjs     ← 실시간 중계 + 파일 서버 + 관리자 API
server/data/         ← 상영목록, 관리자 비밀번호 (자동 생성)
```
